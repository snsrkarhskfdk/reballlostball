재설치·기본 브라우저 변경·다른 프로젝트 Space 초기화는 하지 마.

먼저 실제 origin·브랜치·미커밋 변경을 확인하고 최신 관리파일을 가져와.
사용자 변경을 보존하고 강제 reset/force push를 하지 마.
기존 리볼 checkout을 찾아 사용해. 경로를 모르면 옛 C: 경로나 다른 프로젝트의
D: 경로를 임의로 쓰지 마. 작업공간을 새로 만드는 것은 필요한 경우로 제한해.

AGENTS.md, CONTROL_KO.md, TASKS.json을 읽고 아래 명령으로 현재 상태를 확인해.
node scripts/reball-release-control.mjs validate
node scripts/reball-release-control.mjs status

TASKS에서 R01이 아직 미완료라면 첫 실행은 R01만 수행해. 이미 검증됐다면
현재 연결과 대상 환경을 다시 읽고 첫 미완료 작업에서 이어가. 완료 기록을 초기화하지 마.
실제 Codex 모델·추론 설정·세션 담당자를 기록하고,
Get-Command ego-browser 및 설치된 ego-browser skill 전체 가이드를 읽어.
끝표시까지 읽은 설치본 API를 사용하고 웹 예제/Playwright API를 임의로 섞지 마.
기존 리볼 작업 Space가 있으면 재사용해. 없을 때만 '리볼로스트볼 최종 검증'
전용 Space를 만들고 실제 숫자 ID와 Page label을 TASKS에 기록해.

없을 때만 필요한 승인 한 건을 구체적으로 보고하고, 있으면 출처를 기록하고 진행해.

RECEIPT.template.json을 복사해 실제 관측값으로 채우고 receipts/에 저장해.
node scripts/reball-release-control.mjs receipt <실제 영수증 경로>
검사를 통과하고 증거를 검토한 경우에만 작업을 VERIFIED로 올려.
지정된 실행자 하나만 브라우저를 조작하고, 중단 시 같은 run/Space로 재개해.
반응이 없다고 결제나 주문을 반복하지 말고 기존 결과부터 확인해.

완료/차단 결과를 TASKS와 함께 기존 PR 브랜치에 반영해.
자동 배포 비활성 설정은 유지해. 비밀번호·토큰·결제키·주소·전화번호는 공유하지 마.
마지막 답변은 실제 모델/추론 설정, run ID, Space ID, 작업 결과, 세 SHA,
영수증 경로, 반영 commit, 차단 사유, 다음 작업 한 개로 보고해.
자료만 다시 설명하지 말고 R01 연결 확인을 실제로 수행하거나 정확한 로컬 차단을 남겨.
