# Codex 후속 작업 인계서

## 이번 작업에서 완료된 범위

- `단가 계산.xlsx`의 세로 상품 그룹을 9개 상품군, 54개 가격 옵션으로 반영
- 엑셀 A-를 고객 화면 B로 변환
- 브랜드혼합·일반브랜드 A+ 10구와 A·B 100구 구성 반영
- 일반브랜드 A·B 100구 무료배송을 프런트와 서버 주문금액에 반영
- 타이틀리스트 PRO V1·PRO V1X S등급 5구 17,000원 추가
- 모든 상품에 50구 `가격 준비중` 자리 추가
- 첨부 ZIP의 81개 사진을 WebP로 최적화하고 상품 갤러리에 연결
- A+·A·B 및 타이틀리스트 S 선택 시 실사진과 상태 안내 문구가 함께 변경되도록 구현
- 관리자 상품 수정 화면에 옵션별 가격·재고·사진 편집표 추가
- Supabase 운영 DB에 등급, 가격, 상품, 무료배송 규칙 반영

## 다음 입력을 기다리는 항목

1. 50구 모델·등급별 가격
2. 새로 만든 가격 옵션의 실제 재고
3. 나이스페이 운영 MID·키·웹훅 정보
4. 카카오페이·네이버페이 접수 또는 연동 메일

## 배포 순서 주의

운영 DB의 가격·등급 데이터는 적용됐지만 새 실사진 파일을 포함한 프런트 코드는 아직 배포되지 않았습니다. 다음 작업자는 코드와 `assets/figma/product-actual`을 먼저 같은 배포에 올린 뒤 상세페이지를 확인해야 합니다. 운영 코드 배포 전에는 새 `product-actual/` 경로를 사용하는 일부 옵션 사진이 보이지 않을 수 있습니다.

## 재고 원칙

기존 DB와 모델·등급·구성이 정확히 일치하는 옵션만 기존 재고를 보존했습니다. 새 옵션은 재고 0으로 등록되어 가격은 존재하지만 구매할 수 없습니다. 관리자 화면에서 실제 재고를 입력한 뒤 판매를 시작해야 합니다.
