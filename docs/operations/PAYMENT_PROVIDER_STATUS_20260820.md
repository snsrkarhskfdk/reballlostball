# 결제사 진행상태와 심사 준비

## 현재 판단

- 토스페이먼츠: 홈페이지 주문·결제 연결 코드가 준비되어 있습니다. 운영 키와 상점 설정을 확인한 뒤 운영 결제 검증이 필요합니다.
- 나이스페이: 첨부 프레젠테이션은 결제 연동 키가 아니라 심사 화면 경로 예시입니다. MID·클라이언트 키·시크릿 키·웹훅 정보가 없으므로 실제 결제 연동은 아직 시작할 수 없습니다.
- 카카오페이·네이버페이: 메일이 확인되지 않은 상태입니다. 현재 단계에서는 토스 또는 나이스페이 심사를 먼저 진행할 수 있으며, 두 간편결제사의 접수번호나 재발송 메일이 오면 별도 연동합니다.

## 나이스페이 프레젠테이션에서 확인한 단건결제 심사 경로

1. 쇼핑몰 하단에서 상호, 대표자, 사업자번호, 주소, 전화번호, 이메일, 통신판매업 신고번호, 이용약관, 개인정보처리방침을 확인합니다.
2. 심사 URL에 접속합니다.
3. 비회원 구매가 가능하면 로그인 단계는 생략할 수 있습니다.
4. 테스트·샘플이 아닌 실제 판매 상품 2~3개를 확인합니다.
5. 주문서에서 신용카드를 선택합니다.
6. 결제창과 카드사 인증창까지 총 3개 화면을 캡처합니다.

현재 홈페이지 푸터에는 위 사업자 정보와 약관 링크가 들어가 있습니다. 심사 제출 전에는 재고가 있는 실제 상품 2~3개와 결제창이 운영 환경에서 열리는지 확인해야 합니다.

## 나이스페이 연동을 위해 추가로 필요한 값

- 운영 MID
- 클라이언트 키 또는 상점 키
- 시크릿 키
- 승인·취소 API 사양과 운영 도메인 등록 상태
- 웹훅 서명 검증 정보
- 결제 완료·실패 복귀 URL 등록 상태

키는 문서나 코드에 직접 적지 않고 배포 환경의 비밀 변수로 등록해야 합니다.
