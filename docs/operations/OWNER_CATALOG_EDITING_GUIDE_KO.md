# 리볼 로스트볼 상품 수정 안내

## 관리자가 직접 바꿀 수 있는 항목

관리자 화면 `https://reballlostball.com/#/admin`에서 상품관리로 이동하면 다음 항목을 직접 수정할 수 있습니다.

- 상품명, 브랜드, 상품 설명
- 모델 옵션과 색상 옵션
- 모델·등급·구성별 판매가격
- 모델·등급·구성별 실제 재고
- 대표 이미지와 옵션별 이미지 파일 경로

## 가격 또는 재고 수정 순서

1. 관리자 계정으로 로그인합니다.
2. 왼쪽 메뉴에서 `상품관리`를 누릅니다.
3. 수정할 상품을 선택하고 `상품 수정`을 엽니다.
4. `옵션별 가격·재고·사진` 표에서 해당 행의 가격 또는 재고를 고칩니다.
5. 저장한 뒤 쇼핑몰 상품 상세에서 모델·등급·구성을 다시 선택해 확인합니다.

재고가 `0`인 옵션은 가격이 있어도 결제할 수 없습니다. 실제 판매할 수량만 입력해야 합니다.

## 50구 가격을 받았을 때

각 상품의 50구 행은 `가격 준비중` 상태로 미리 만들어져 있습니다.

1. 해당 모델·등급의 50구 행을 찾습니다.
2. 가격을 `0`에서 실제 판매가로 바꿉니다.
3. 실제 재고를 입력합니다.
4. 저장하면 50구 선택 버튼이 자동으로 열립니다.

가격이 `0`인 동안에는 고객이 50구를 선택하거나 결제할 수 없습니다.

## 등급 표기 규칙

- S: 타이틀리스트 PRO V1·PRO V1X 전용, 5구 17,000원
- A+: 10구 최상급
- A: 엑셀의 A등급
- B: 엑셀의 A-등급을 고객 화면에서 알기 쉽게 바꾼 표기
- 100구: 브랜드혼합·일반브랜드의 A·B만 제공

## 사진 수정 시 주의사항

관리자 화면에서 입력하는 값은 이미 홈페이지에 올라간 사진의 파일 경로입니다. 예: `product-actual/titleist-pro-v1-01.webp`

새 사진 파일 자체를 올리는 기능은 아직 없습니다. 새 사진을 추가하려면 파일 최적화와 배포가 필요하므로 Codex 작업으로 넘겨야 합니다. 이미 등록된 사진끼리 바꾸는 작업은 관리자 화면에서 할 수 있습니다.

## 문제가 생겼을 때

- 저장 후 옵션이 사라짐: 가격이 0인지 확인합니다.
- 구매 버튼이 비활성화됨: 해당 옵션의 재고가 0인지 확인합니다.
- 사진이 깨짐: 파일 경로 앞에 `/products/`를 넣지 말고 관리자 표에 보이는 기존 형식을 사용합니다.
- S등급이 다른 브랜드에 보임: 저장하지 말고 Codex에 확인을 요청합니다.
